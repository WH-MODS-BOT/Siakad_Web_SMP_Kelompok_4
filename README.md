Sistem Informasi Akademik (SIAKAD) berbasis web yang dirancang khusus untuk memenuhi kebutuhan administrasi dan manajemen data akademik di tingkat Sekolah Menengah Pertama (SMP). Aplikasi ini mempermudah pengelolaan data siswa, guru, nilai, hingga jadwal pelajaran secara terintegrasi.
---
## 📌 Fitur Utama
Aplikasi ini dilengkapi dengan fitur berbasis peran (*Role-Based Access Control*) untuk memastikan keamanan dan relevansi akses data:
### 👨‍💼 Panel Administrator
* 🔐 **Manajemen Pengguna:** Pengelolaan akun guru, siswa, dan staf sekolah.
* 🏫 **Manajemen Data Kelas & Mata Pelajaran:** Pengaturan alokasi kelas, wali kelas, dan kurikulum mata pelajaran.
* 📅 **Penjadwalan Pelajaran:** Penyusunan dan pembaruan jadwal kegiatan belajar mengajar (KBM).
* 📈 **Rekapitulasi Data:** Akses laporan akademik dan statistik sekolah secara rinci.
### 👩‍🏫 Panel Guru
* 📝 **Input Nilai:** Pengisian nilai tugas, UTS, UAS, dan rekap penilain harian.
* 📋 **Presensi Siswa:** Pencatatan kehadiran harian siswa di kelas.
* 📖 **Jadwal Mengajar:** Lembar acuan jadwal mengajar harian/mingguan.
### 👨‍🎓 Panel Siswa
* 📊 **Transkrip & Rapor:** Melihat hasil capaian nilai akademik per semester.
* 🗓️ **Jadwal Pelajaran:** Mengakses informasi jadwal pelajaran yang berlaku.
* 📌 **Informasi Presensi:** Memantau rekapitulasi tingkat kehadiran pribadi.
